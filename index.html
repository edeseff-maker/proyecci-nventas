Precio unitario
Precio(mes N) = Precio base dic × ∏(1 + IPC_i) para i = 1 a N. La inflación se acumula mes a mes.
Ventas
Dto. condición
% fijo sobre venta bruta, igual para todos los meses.
Dto. ofertas
% variable por mes sobre venta bruta. Se ingresa en cada tarjeta mensual.
Ganancia
% fijo sobre venta bruta, igual para todos los meses.
Venta neta
Venta bruta − Dto. condición − Dto. ofertas + Ganancia.
Costos
Costo bruto
% de costo sobre venta bruta ingresado en cada tarjeta mensual, aplicado sobre la venta bruta de ese mes.
Dto. laboratorios
% positivo aplicado sobre el costo bruto (representa una ganancia/recupero). El campo global define la base. En cada tarjeta mensual se sugiere automáticamente un ajuste según la inflación proyectada: por cada punto porcentual que baja la inflación respecto al mes anterior, el descuento sugerido sube 0,3 puntos (factor de sensibilidad = 0,3), y viceversa. Esta lógica refleja que en contextos de menor inflación los laboratorios suelen ofrecer mejores condiciones comerciales. Todos los valores son editables manualmente.
Costo neto
Costo bruto − Dto. laboratorios.
Margen bruto
Venta neta − Costo neto.
