Días parciales
Sábados, feriados puente, no laborables y bancarios se computan al 60 % de un día hábil. Domingos y feriados inamovibles o trasladables se computan como 0 % (sin ventas).
Precio unitario
El precio de cada mes se obtiene aplicando la inflación mensual acumulada al precio base de diciembre del año anterior: Precio(mes N) = Precio base × ∏(1 + IPC_i) para i=1 a N.
